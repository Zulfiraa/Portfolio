Ecommerce Customer Segmentation

Analyzed ecommerce customers data to identify customer groups with different levels of engagement and monetary value..

Dataset

1,642 transaction records

Tools

Python

Visual Studio Code

Focus

Customer Segmentation

Project Objective

The objective of this project was to analyze segment e-commerce customers based on their purchasing behavior using RFM (Recency, Frequency, Monetary) analysis and K-Means clustering, in order to identify valuable customer groups and support targeted marketing strategies.

Data Analysis

The analysis was conducted using Python and applies RFM analysis to measure customer recency, purchase frequency, and monetary value. K-Means clustering is then used to group customers with similar purchasing characteristics. The optimal number of clusters is evaluated using the Elbow Method and Silhouette Score.

01. RFM Analysis

Calculated Recency, Frequency, and Monetary metrics to measure customer purchasing behavior.

02. Data Transformation

Applied log transformation and standardization to prepare the RFM variables for clustering.

03. Cluster Evaluation

Tested K-Means with K = 2–10 using the Elbow Method and Silhouette Score.

04. K-Means Clustering

Selected K = 2 based on the highest Silhouette Score of 0.3632 and analyzed the characteristics of each customer segment.

Key Insights

  • Cluster 0 (More Active Customers) represents 50.95% of customers but contributes 77.14% of total revenue.
  • Cluster 1 (Less Active Customers) represents 49.05% of customers but contributes only 22.86% of revenue.

Conclusion

The analysis suggests that Cluster 0 is the more valuable and active segment (77.14% of revenue), while Cluster 1 is less active and lower-value. The segmentation can be used to develop differentiated strategies, such as customer retention and loyalty programs for Cluster 0 and reactivation campaigns for Cluster 1.
